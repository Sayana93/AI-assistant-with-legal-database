# ИИ-ассистент муниципального служащего (MVP)

Мой первый практический проект на Python, созданный для участия в конкурсе «Лучший муниципальный служащий» . 

## Идея проекта
Хотелось совместить личный интерес к программированию с реальными задачами. На подготовку официальных документов — ответов на заявления граждан, запросы или требования прокуратуры — уходит очень много времени. 

Конечно, существуют универсальные модели вроде GigaChat или Gemini, но мне было интересно попробовать создать узкоспециализированный инструмент, который говорит именно на профессиональном юридическом языке и заточен под конкретные задачи муниципальных служащих. 

## Что сделано в прототипе
- С помощью нейросети помощником написан и собран код Python.
- Подключено GigaChat API с учетом специфики составления документов в официальном стиле.
- Добавлена обработка PDF-документов через PyPDF2.
- Собран интерактивный веб-интерфейс на Streamlit, работающий прямо в браузере.

## 🛠️ Стек технологий
- Python
- Streamlit
- GigaChat API
- PyPDF2
